moon check --deny-warn --target js examples/moonlsm

moon test --target wasm-gc .
moon test --target js .
moon run --target js examples/moonlsm
python examples/moonlsm/verify_sqlite.py --baseline

全扫与范围扫描的数据量指存储引擎返回给调用方的键值载荷。示例使用内存存储，MoonFST 快照保存键和序号。本记录涵盖本地构建和复验。
